# Automated Trip Report Generation

Автоматизированное формирование отчёта по поездкам пассажиров из SQLite‑базы.

## Цель
Автоматизировать ручной сбор статистики: получить топ-пассажиров по количеству поездок, вместо ручного подсчёта в Excel.

## Стек
- Python
- pandas
- sqlite3
- SQL (JOIN, GROUP BY, COUNT)

## Что делает скрипт
1. Подключается к локальной базе `demo.db`.
2. Выполняет SQL-запрос с `JOIN` таблиц `passenger` и `pass_in_trip`.
3. Агрегирует данные: считает количество поездок для каждого пассажира.
4. Сохраняет итоговый отчёт в `passenger_trips_report.csv`.

## Результат
Файл `passenger_trips_report.csv` с колонками: `passenger_name`, `trips_count`.
